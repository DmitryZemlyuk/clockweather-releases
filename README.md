# Clock & Weather — APK releases

Android home-screen clock and weather widget («Годинник і погода»). This repository holds **APK releases only**; the app checks the latest release here and offers to update itself.

- Install: download `ClockWeather-<version>.apk` from [Releases](https://github.com/DmitryZemlyuk/clockweather-releases/releases) and open it on the phone.
- Updates install over the previous version and keep all settings (same signing key).
- Requires Android 10 or newer.

Weather data: [Open-Meteo](https://open-meteo.com) (CC BY 4.0) and [MET Norway](https://api.met.no) (CC BY 4.0).
